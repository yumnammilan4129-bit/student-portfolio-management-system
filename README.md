# Student Portfolio Management System

A web-based application that allows multiple students
to register, log in and manage their personal portfolios.

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose

## Main Features
- User registration and login
- Portfolio management
- Add, view, update and delete details
- Feedback submission
- User logout

## How to Run
1. Install Node.js and MongoDB.
2. Open the project folder in the terminal.
3. Run npm install.
4. Create a .env file with the required configuration.
5. Run npm start.
6. Open http://localhost:3000.
